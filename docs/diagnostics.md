# Diagnostics

## Space-time covariance

`stcov` makes the temporal direction explicit:

```python
from pystarmax import stcov

gamma = stcov(
    data,
    weights,
    past_spatial_lag=1,
    future_spatial_lag=0,
    temporal_lag=2,
)
```

This is important for non-symmetric row-standardized matrices: exchanging the
past and future spatial lags need not produce the same sample covariance.

## STACF

`stacf` returns temporal lag zero through `max_tlag`. Lag zero is retained for
auditing even though identification plots commonly begin at lag one.

```python
acf = stacf(data, weights, max_tlag=8)
```

## STPACF

The default is the classical nested Yule–Walker method:

```python
pacf = stpacf(data, weights, max_tlag=4)
```

For every temporal–spatial index, pySTARMAx solves the corresponding leading
principal covariance system and retains its newest coefficient.
`solver="auto"` first attempts a direct solve and uses least squares only when a
system is singular. Use `solver="solve"` to require a nonsingular system.

The 0.0.1 regression diagnostic remains available explicitly:

```python
legacy = stpacf(data, weights, max_tlag=4, method="regression")
```

It is a useful projection diagnostic but should not be described as the
classical Yule–Walker STPACF.

## Independent reference fixture

`tests/reference/classic_diagnostics_v1.json` is generated by
`tools/generate_classic_diagnostics_reference.py`. The generator imports no
pySTARMAx code. It uses exact `fractions.Fraction` arithmetic and an independent
Gauss–Jordan solver, with a deliberately non-symmetric weight matrix. CI
regenerates the fixture and rejects any uncommitted difference.
