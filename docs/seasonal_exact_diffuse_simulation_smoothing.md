# Seasonal exact-diffuse simulation smoothing

Version 0.0.31 adds dense conditional path simulation for the complete seasonal
exact-diffuse augmented state associated with

\[
x_t=(1-B)^d(1-B^s)^D y_t.
\]

The implementation conditions latent paths on the original observations. It
then exposes both the complete augmented state and the stationary transformed
state from the same posterior draws.

## Fitted-model interface

```python
paths = model.simulate_smoothing_paths(
    n_simulations=1000,
    random_state=42,
)
```

The returned
`SeasonalExactDiffuseSimulationSmootherResult` contains:

```python
paths.state_paths
paths.observation_paths
paths.transformed_state_paths
paths.transformed_observation_paths
paths.posterior_state_mean
paths.posterior_state_covariance
paths.posterior_transformed_state_mean
paths.posterior_transformed_state_covariance
```

`state_paths` has shape
`(n_simulations, n_time, augmented_state_dimension)`. The original-level
observation paths have shape `(n_simulations, n_time, n_locations)`.

Passing new observations starts a fresh exact-diffuse initialization under the
fitted parameters:

```python
new_paths = model.simulate_smoothing_paths(
    new_level_data,
    n_simulations=1000,
    random_state=42,
)
```

This is not continuation filtering from the terminal training posterior.

## Functional interface

```python
from pystarmax import seasonal_exact_diffuse_simulation_smoother

paths = seasonal_exact_diffuse_simulation_smoother(
    filter_result,
    integrated_state_space,
    n_simulations=1000,
    random_state=42,
)
```

The supplied `ExactSeasonalIntegratedStateSpace` must be the exact object whose
`model` was used by `filter_result`. This identity check protects the block
layout used for transformed-state projection.

## Conditional Gaussian construction

The generic exact-diffuse simulation smoother writes the latent path as a
linear function of:

- initial diffuse coordinates;
- initial proper finite coordinates;
- primitive innovations through time.

Observed cells form exact linear constraints on those sources. Diffuse
coordinates are eliminated analytically, and the remaining proper Gaussian
source vector is conditioned and sampled. The complete seasonal augmented state
therefore uses the same validated source-conditioning algorithm as the ordinary
exact-diffuse model.

No seasonal approximation and no finite large-variance initialization are
introduced.

## Transformed-state projection

Let

\[
m=d+Ds
\]

be the degree of the combined differencing polynomial. For positive seasonal
integration the augmented state begins with `m` original-level lag blocks and
then stores the stationary transformed STARMA state. The transformed block
starts at

\[
m n_{\text{locations}}.
\]

For every conditional draw,

```python
transformed_state_paths = state_paths[..., offset:]
transformed_observation_paths = (
    transformed_state_paths @ transformed_model.design.T
)
```

The transformed paths are thus exact projections of the same original-level
conditional paths. They are not generated by a second smoother.

## Exact observation constraints

For every finite input cell `(t, i)`, the simulated original-level observation
satisfies

\[
y_{t,i}^{(r)}=y_{t,i}
\]

up to numerical tolerance for every replication `r`. Missing cells are sampled
from their joint conditional distribution and retain cross-time and cross-state
dependence.

For a period-two seasonal random walk,

\[
y_t=y_{t-2}+\eta_t,
\]

the transformed paths satisfy the pathwise identity

\[
x_t=y_t-y_{t-2}
\]

for every draw.

## Proper-posterior requirement

A conditional Gaussian draw requires all diffuse directions to be identified by
the observed sample. The method therefore requires

```python
filter_result.final_diffuse_rank == 0
```

and raises `RuntimeError` otherwise. It never replaces an unresolved diffuse
direction with an arbitrary finite covariance.

## Verification diagnostics

The underlying result records:

- `diffuse_rank`;
- `conditioning_rank`;
- `proper_source_dimension`;
- `posterior_source_dimension`;
- `maximum_constraint_residual`;
- `maximum_mean_discrepancy`;
- `maximum_covariance_discrepancy`.

Posterior marginal means and covariances are checked against the generic
exact-diffuse information smoother. Result arrays are immutable.

## Ordinary reduction

When `seasonal_integration_order=0`, the existing ordinary exact-integrated state
construction is reused. Under the same seed, the wrapped complete state and
observation draws reduce exactly to `exact_diffuse_simulation_smoother`.

## Computational scope

The method is a dense moderate-sample reference implementation. Building and
factoring the source-conditioning system can be expensive for long time series,
large spatial systems, or many missing cells.

Version 0.0.31 does not provide:

- diffuse lag-one smoothed covariance;
- cross-time primitive-disturbance covariance;
- parameter-uncertainty propagation;
- bootstrap refitting;
- sparse, chunked, or parallel conditioning.

These remain separate future projects so that the exact posterior contract stays
auditable.
